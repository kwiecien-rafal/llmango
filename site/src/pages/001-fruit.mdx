-experiment description here, with motivation -

## questions

Every question in experiment 001 shares one fruit list, one canonical category set
and one response schema. Each varies exactly one thing:

- **001a**: fixed option order, asked in English, Polish and Japanese.
- **001b**: English only, a second fixed order over the same list.
- **001c**: a per-sample shuffle across the same three languages, which kills
  position as a confound within a language.
- **001d**: a Polish prompt with three schema arms (English, Polish, and free text
  response with no schema at all). The response schema is the only variable.
